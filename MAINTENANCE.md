Releasing
=========

Use the signed manual release workflow documented in
[scripts/release/README.md](scripts/release/README.md).
Before dispatch, complete the release-note classification and label verification
in [CONTRIBUTING.rst](CONTRIBUTING.rst#github-releases-and-release-notes).
Generated GitHub notes exclude `omit-from-release-notes`; existing draft and
published notes are preserved on reruns.

After the release workflow succeeds, publish a release announcement on the
community forum.
